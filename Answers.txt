1. What is the slope?
A.The slope is represented by the coefficient values of the model. It shows how much the predicted marks change when a feature increases by one unit.


2. What is the intercept?
A.The intercept is the value of the prediction when all feature values are zero.


3. What do they mean?
A.The coefficients show the effect of Study Hours, Attendance, and Assignments on Marks. The intercept acts as the starting point of the prediction equation.


4. What is MAE?
A.MAE (Mean Absolute Error) measures the average difference between actual values and predicted values. Lower MAE indicates better model performance.


5. What is R² Score?
A.R² Score measures how well the model explains the variation in the target variable. Its value ranges from 0 to 1, and values closer to 1 indicate a better fit.


6. Is your model performing well?
A.Yes. The model is performing well if the MAE is low and the R² Score is close to 1.


Research Section 


1. What is Machine Learning?
A.Machine Learning is a branch of Artificial Intelligence that enables computers to learn from data and improve their performance without being explicitly programmed. Instead of following fixed instructions, machine learning algorithms identify patterns in data and use those patterns to make predictions or decisions. It is widely used in modern technology such as recommendation systems, speech recognition, image recognition, and fraud detection. Machine learning models are trained using historical data and then tested on new data to evaluate their performance. The more relevant data a model receives, the better it can learn and make accurate predictions. Machine learning helps automate complex tasks and supports data-driven decision making. It is one of the most important technologies in today's digital world and is used across healthcare, education, finance, transportation, and many other industries.


2. What is Linear Regression?
A.Linear Regression is a supervised machine learning algorithm used to predict continuous numerical values. It establishes a relationship between one or more independent variables (features) and a dependent variable (label). The algorithm fits a straight line that best represents the relationship between the input variables and the target variable. This line is known as the regression line. Linear Regression is commonly used for predicting prices, marks, salaries, sales, and other measurable quantities. The model calculates coefficients and an intercept to create a mathematical equation for prediction. It is easy to understand, simple to implement, and serves as a foundation for learning more advanced machine learning algorithms. Because of its simplicity and effectiveness, Linear Regression is widely used in data analysis and predictive modeling.


3. What are Features?
A.Features are the input variables used by a machine learning model to make predictions. In this assignment, Study_Hours, Attendance, and Assignments are the features because they influence student marks. Features provide information that helps the model learn patterns from data. Selecting relevant features is important because it improves model accuracy and performance. Features can be numerical or categorical depending on the dataset.


4. What are Labels?
A.Labels are the output values that a machine learning model predicts. In this assignment, Marks is the label because it is the target value we want to predict. Labels represent the correct answers used during model training. The model learns the relationship between features and labels and then uses that knowledge to predict labels for new data.


5. Difference Between Training Data and Testing Data?
A.Training data is the portion of the dataset used to teach the machine learning model. The model learns patterns and relationships from this data. Testing data is a separate portion of the dataset used to evaluate how well the trained model performs on unseen data. Training data helps build the model, while testing data measures its accuracy and reliability. Splitting data prevents overfitting and helps determine whether the model can generalize to new situations.


6. Where is Machine Learning Used in Real Life?
A Machine Learning is used in many real-world applications. Streaming platforms like Netflix and YouTube use it for recommendations. Banks use it to detect fraud and assess credit risk. Healthcare organizations use machine learning to assist in disease diagnosis and medical image analysis. E-commerce websites use it to suggest products and personalize shopping experiences. Voice assistants such as Siri and Google Assistant use machine learning for speech recognition. Self-driving vehicles, cybersecurity systems, weather forecasting, education platforms, and social media applications also rely heavily on machine learning technologies.
